# Installation

For the official Claude Code VS Code extension, open `/plugin`, add `Weslley08/cmr` as a marketplace and install `model-router@cmr` with user scope. See [INSTALL.md](../../../INSTALL.md).

An optional Rust CLI provides diagnosis and installation via the `claude` terminal executable when available. It can be built with `cargo build --release`. No WinGet or Homebrew package is available yet.

Automatic per-request model routing requires the Mod; native `UserPromptSubmit` settings hooks provide only advice.
