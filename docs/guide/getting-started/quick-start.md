# Quick start (experimental)

1. In the Claude Code plugin manager, add `Weslley08/cmr` as a plugin marketplace source.
2. Install `model-router@weslley08-cmr` for the user and restart the session.
3. Run `/cmr status`, `/cmr mode balanced`, `/cmr auto`.
4. Try a scoped read-only question, a regular coding task and a complex architecture task.
5. Inspect the **actual model selected** by Claude Code, not only CMR's suggested model.
6. Disable routing with `/cmr off` if needed.

The integration has not yet passed real Claude Code host tests.
